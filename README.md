# Spear Consulting | رمح للاستشارات

Bilingual (EN/AR), light and dark website for Spear Consulting.

Single self-contained `index.html`. Open it directly or serve it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Note: the Arabic font here is IBM Plex Sans Arabic (Google Fonts). Thmanyah font files are licensed for the live site only and are not stored in this repo.
